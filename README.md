# 🎯 TARGET — Learning Management System

This is a Learning Management System (LMS) project developed using React, Tailwind CSS, Python and Django REST Framework. I created this project to practice frontend and backend development skills and build a real-world online learning platform.

## Features

* Sign up and log in securely
* Three user roles: Student, Instructor and Admin
* Browse courses with thumbnail, category and price
* Enrollment request with admin approval
* Video lessons with YouTube support
* Lesson progress tracking
* Recorded videos section
* Instructor profiles
* Admin panel to manage users and categories
* Fully responsive design
* Clean and modern user interface

## Technologies Used

* Frontend: React, Tailwind CSS
* Backend: Python, Django REST Framework
* Database: SQLite
* Tools: Git & GitHub, Postman

## Project Goal

The main goal of this project is to create an online platform where instructors can share their courses and students can learn easily from anywhere. Admin keeps full control over users, courses and enrollments.

## Main Modules

* Login & Signup
* Dashboard
* Courses
* Course Details
* Lessons
* Recorded Videos
* Instructors
* My Courses (Instructor)
* Course & Lesson Management
* User Management (Admin)
* Category Management (Admin)
